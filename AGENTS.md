# Neural Flight

## Project graph

- For architecture, dependencies, or cross-file behavior, start with [the Graphify report](graphify-out/GRAPH_REPORT.md).
- From the repository root, use `graphify query "<question>"` or `graphify explain "<symbol>"` when the CLI is available. The report and [graph JSON](graphify-out/graph.json) are usable without installing Graphify.
- Verify important findings against the source. Check for changes to the relevant files since the graph's recorded source commit, especially when following inferred edges.
